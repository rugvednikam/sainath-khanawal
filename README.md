## 🍽️ Key Features

- **Authentic Maharashtrian Heritage Design:** Warm terracotta and turmeric aesthetic tailored for local Puneri diners and tourists.
- **Real Photography:** Actual photographs of Sainath Khanawal's Special Mutton Thali, Gavran Chicken Thali, piping hot Kala Rassa, Jowar Bhakris, and Solkadhi.
- **Interactive Menu & Pricing:** Tabbed category filtering (Thalis, Mutton Specials, Chicken Specials, Egg & Veg, Accompaniments) with a live instant search bar.
- **Khanawal Dining Guide:** House customs explaining the unlimited rassa refill culture, peak rush advice, parcel packaging, and spice balance.
- **Direct WhatsApp Ordering:** 1-click WhatsApp messaging pre-filled with Marathi/English order inquiries.
- **Local SEO & Schema.org Structured Data:** Complete `Restaurant` + `FAQPage` JSON-LD schema with `AggregateRating` (4.3★ over 4,850+ reviews) and geo-coordinates for Google search rich snippets.
- **Mobile-First UX:** Sticky bottom navigation bar for one-tap calling, WhatsApp messaging, and Google Maps directions.

## 🚀 Running Locally

You don't need any complex dependencies. Simply serve the static directory:

```bash
# Using Python 3
python -m http.server 8080

# Or with Node
npx serve .
```

Open `http://localhost:8080` in your web browser.
